# Flux

Бесконечный аркадный 3D-раннер. Игрок скользит внутри жёлоба-полуцилиндра,
который уходит вперёд и вниз. Гравитация разгоняет по склону, A/D смещают
персонажа по дуге, Space - прыжок. По пути попадаются препятствия, монеты,
аптечки и орбы временных мутаций, которые меняют правила забега (жёлоб
замыкается в трубу, скорость растёт, управление инвертируется и т.д.).

Цель - продержаться дольше всех и побить локальный рекорд.

## Управление

- `A` / `D` или стрелки - движение по дуге
- `Space` - прыжок
- `Esc` - пауза
- любая клавиша - старт и рестарт

## Реализация

Движение - кинематика. Положение игрока задают два числа:
пройденный путь `s` по трассе и угол `theta` по сечению жёлоба. Вперёд тянет
проекция гравитации на касательную, вбок работает маятник: руль добавляет
момент, гравитация отбирает. Высота подъёма оплачивается скоростью - подъём
её тратит, спуск возвращает с небольшим бонусом.

Трасса - одна непрерывная кривая. Повороты и спуски задаются формулой из синусов. 
Дальше трасса прокладывается вперёд шагами по одному метру, и каждая точка запоминается. 
Жёлоб рисуется по этим точкам, и движение считается по ним же.

Стриминг чанками по 24 м. Меш чанка - чистая функция от его индекса,
поэтому чанки не хранят состояния и свободно переиспользуются из пула.
Дальше тумана геометрия не строится.

Препятствия вырезаны из самой трубы. Они повторяют кривизну жёлоба и сидят
вровень с поверхностью, поэтому силуэт и хитбокс совпадают. Коллизии считаются
в координатах жёлоба (путь, угол, высота).

Расстановка детерминирована по индексу чанка, а сид меняется на каждый
забег, так что трассы не повторяются. Пикапы проверяются на зазор от
препятствий и друг от друга: монет внутри препятствий или орбов внутри монет
не бывает.

Мутации сводятся к набору множителей (гравитация, скорость мира, знак
руля, радиус сбора), которые читают игрок, объекты и камера. Меняющие форму
мутации (труба, сужение) пересобирают жёлоб один раз при переходе.

## Файлы

`Assets/Scripts/`

- `Track.cs` - геометрия трассы: узлы, позиция, нормаль поверхности
- `GrooveStream.cs` - поток и пул чанков жёлоба
- `Props.cs` - препятствия, монеты, орбы, аптечки и коллизии
- `PlayerMotor.cs` - движение, прыжок, визуал состояний
- `CameraRig.cs` - камера, тряска, виньетка, динамический туман
- `Mutation.cs` - система временных мутаций
- `Run.cs` - состояние забега, здоровье, счёт, рекорд
- `Hud.cs` - весь интерфейс, собирается в рантайме

`Assets/Shaders/Sky.shader` - шейдер градиентного неба.

## Настройка

Все параметры - публичные поля в инспекторе:

- `Track` - форма трассы, уклон, амплитуда поворотов и провалов
- `Player` - скорость, управление, прыжок, штраф за удар
- `Game → Props` - плотность объектов, зазоры, частота пикапов
- `Game → Mutation` - число одновременных мутаций
- `Game → Run` - здоровье, неуязвимость
- `Main Camera → CameraRig` - камера, виньетка, туман
